# Ontologia dei contenuti

I tipi di contenuto del sito. Ogni tipo ha campi fissi e vive in una cartella di `src/content/`. La stessa struttura diventerà i blueprint di Kirby.

| Tipo | Campi principali | Note |
|---|---|---|
| **Pagina** | titolo, intro, sezioni | Home, Risorse, La Ricerca, Team, Contatti |
| **Profilo** | nome, colore, illustrazione, testi | Insegnanti (rosa), Famiglie (arancione), Professionisti (blu) |
| **Fase** | numero, titolo, descrizione | Slider delle fasi del progetto |
| **Video Toolkit** | titolo, descrizione, strumento, parte del corpo, profilo di riferimento, durata, sottotitoli/trascrizione, link al video | Video di Laura sulle posture corrette. È il contenuto destinato a crescere di più, per questo è una collezione a sé e filtrabile |
| **Diary** | *da definire* | Contenuti video; il formato non è ancora deciso. Tipo segnaposto |
| **Risorsa** | titolo, tipo, link/file | |
| **Pubblicazione** | titolo, autori, anno, link | Per La Ricerca |
| **Persona** | nome, ruolo, ente, foto | Per Il team |
| **Partner** | nome, logo, link | SUPSI, SUM-CSI, FNS e collaboratori |

## Regole

- I contenuti testuali sono definitivi: si inseriscono così come sono, senza riscriverli.
- Ogni nuovo tipo di contenuto va prima aggiunto qui, poi nel codice.
